# Banco de dados — BioStat Lab

Fonte: Pesquisa Nacional de Saúde (PNS 2019) — IBGE.

População didática composta por 1.000 indivíduos adultos,
selecionados aleatoriamente entre 6.571 registros elegíveis
com medidas antropométricas válidas.

Seleção sem reposição, com semente aleatória fixa de 2019.

O banco destina-se exclusivamente a atividades educacionais.
Não constitui uma amostra representativa da população brasileira.
